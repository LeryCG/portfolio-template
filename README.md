# Portfolio Template

Demo / Despliegue en producción

https://lerycg.github.io/portfolio-template/

Descripción y propósito del proyecto

Este proyecto es una plantilla de portafolio web pensada para artistas y profesionales del área de ilusración que desean presentar su perfil, habilidades y proyectos de forma clara, moderna y personalizable.

El propósito principal de esta plantilla es servir como:

Base reutilizable para portafolios personales

Punto de partida para proyectos frontend

Ejemplo de estructura limpia y buenas prácticas en desarrollo web

La plantilla puede adaptarse fácilmente a distintos perfiles profesionales modificando únicamente el contenido y los estilos.

Stack tecnológico

HTML5 — Estructura semántica

CSS3 — Estilos y diseño responsive

JavaScript (ES6+) — Interactividad

Git & GitHub — Control de versiones

GitHub Pages — Despliegue

Instrucciones de configuración para desarrollo local

Clona el repositorio:

git clone https://github.com/lerycg/portfolio-template.git


Accede a la carpeta del proyecto y abre el archivo index.html en tu navegador o utiliza un servidor local.

Guía de personalización

La plantilla está diseñada para ser fácilmente modificable:

Información personal

Edita el nombre, descripción, enlaces y textos directamente en el archivo index.html.

Colores y estilos

Modifica la paleta de colores, tipografías y estilos generales desde los archivos CSS.

Proyectos

Añade, edita o elimina proyectos duplicando la estructura HTML existente en la sección de proyectos.

Imágenes

Sustituye las imágenes actualizando las rutas por URLs externas según tus necesidades.

Política de uso de agentes de IA

En este proyecto se utilizaron asistentes de IA únicamente como herramienta de apoyo técnico y conceptual, no como generadores directos del código final.

La IA se empleó para:

Ayudar ver problemas en el código

Explorar enfoques técnicos

Planificar implementaciones antes de escribir el código

Las decisiones de diseño, estructura y desarrollo fueron tomadas por el autor.
